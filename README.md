# Course Companion · 看课小帮手

> 基于 Playwright 的视频课程自动学习助手：自动登录、保持视频播放、自动应答课中问题、自动推进课时。
>
> English documentation: [README_EN.md](README_EN.md)

## 这是什么

一个把「看在线视频课程」里重复性操作交给程序的桌面助手。它驱动一个真实的浏览器窗口（非无头模式），模拟真人操作：

- **自动登录**：账号密码自动填入；验证码截图自动弹出，你看一眼输入数字即可，脚本自动填入提交
- **保持播放**：视频暂停自动恢复；「加载出错」自动刷新（进度保存在服务端，不丢失）
- **课中应答**：播放中弹出的随堂问题，自动读取页面内置的参考答案并作答；读不到答案时等待人工处理，不会瞎选
- **课时推进**：观看时长达标后自动进入下一节；已完成的节自动跳过
- **直达定位**：从「学习进度」页面直接定位第一个未完成的课时，无需逐节翻找
- **会话续期**：Cookie 定期刷新保存，挂机学习期间几乎不会掉线

到达需要本人独立完成的考核/测验环节时，助手会自动停下。

## 环境要求

- Windows 10/11（使用了 `os.startfile` 自动打开验证码图片）
- Python 3.9+

## 安装

```bash
# 国内镜像加速
pip install playwright -i https://pypi.tuna.tsinghua.edu.cn/simple
python -m playwright install chromium
```

或国际网络环境：

```bash
pip install playwright
python -m playwright install chromium
```

## 快速开始

```bash
python course_companion.py
```

首次运行会依次弹出 4 个配置窗口（仅此一次）：

| 序号 | 内容 | 示例 |
|------|------|------|
| 1 | 登录账号 | 手机号 / 学号 |
| 2 | 登录密码 | 你的密码 |
| 3 | 平台首页地址 | `https://xxx.edu.cn/home` |
| 4 | 课程列表页地址 | `https://xxx.edu.cn/courses` |

配置保存在 `credentials.local.json`（Base64 编码存储）。之后每次启动直接免登录进入课程。

## 配置文件说明

| 文件 | 用途 | 是否入库 |
|------|------|----------|
| `credentials.local.json` | 账号/密码/平台地址（Base64 编码） | ❌ 已被 `.gitignore` 排除 |
| `credentials.local.json.example` | 配置模板（示例值） | ✅ |
| `auth.json` | 登录会话 Cookie（自动生成） | ❌ 已被 `.gitignore` 排除 |

- 修改密码或换账号：删除 `credentials.local.json` 重新运行
- 换电脑：把项目拷过去，删除 `credentials.local.json` 重新配置即可

## 使用注意

1. **保持窗口前台**：学习期间让浏览器窗口保持前台（可以缩小尺寸，不要最小化），部分平台会暂停后台标签页的计时
2. **不要多开**：同一账号多窗口/多设备同时观看时，多数平台只记录其一
3. **验证码**：每次掉线后重新登录需要你输入一次验证码（看图输数字，10 秒）；会话续期机制让它很少出现
4. **考核环节**：需要本人独立完成的测验，助手会自动停下

## 工作原理

- Playwright 有头模式驱动 Chromium，所有点击都是完整的真实鼠标事件序列
- 课中问题的参考答案直接从页面内嵌脚本中提取（页面自身携带），多级解析策略保证稳定性
- 每 20 秒轮询一次页面状态：进度文案 → 播放状态 → 弹窗检测
- 会话通过 `storage_state` 持久化，并在每个课时完成后自动续存
